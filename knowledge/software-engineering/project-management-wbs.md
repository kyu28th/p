# WBS

## 1-Line Definition

WBS is a hierarchical decomposition of the total project scope into manageable work units, with Work Package as the lowest management unit.

## Why It Matters

WBS becomes the basis for scope, schedule, cost, assignment, risk, communication, and performance control. In the exam, WBS questions often ask not only "what it is" but also principles, benefits, and considerations.

## Core Structure

```text
Project
-> Deliverable or phase
-> Sub-deliverable
-> Work Package
-> Activity
```

## Key Features

| Item | Meaning |
|---|---|
| Work Package | Lowest manageable WBS unit |
| 100% Rule | Child work must cover 100% of parent scope |
| WBS Dictionary | Description of WBS elements, scope, owner, deliverable, and criteria |
| Scope Baseline | Approved scope statement + WBS + WBS dictionary |

## Exam Answer Frame

```text
I. WBS concept and need
II. WBS structure and key components
III. Creation principles: hierarchical decomposition, deliverable orientation, 100% Rule, manageable level
IV. Use in schedule, cost, resource, risk, communication, and control
V. Considerations and conclusion
```
