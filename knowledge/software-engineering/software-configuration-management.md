# Software Configuration Management

## 핵심 정의

소프트웨어 형상관리는 소프트웨어 생명주기에서 산출물의 변경을 체계적으로 식별, 통제, 기록, 감사하여 제품의 일관성과 추적성을 확보하는 관리 활동이다.

## 주요 활동

| 활동 | 공식 용어 | 핵심 의미 |
|---|---|---|
| 형상식별 | Configuration Identification | 관리 대상 형상항목을 선정 |
| 형상통제 | Configuration Control | 변경 요청을 검토하고 승인/기각 |
| 형상상태보고 | Configuration Status Accounting | 버전, 변경 진행상태, 반영 내역을 기록/보고 |
| 형상감사 | Configuration Audit | 승인 변경이 실제 산출물에 반영됐는지 검증 |

## CI

CI는 Configuration Item의 약자로 형상항목을 의미한다.

예:

- 소스코드
- 설계서
- 테스트 문서
- 빌드/배포 산출물

## 시험용 목차

1. 개념
2. 필요성
3. 주요 활동
4. 기대효과
