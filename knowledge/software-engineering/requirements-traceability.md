# Requirements Traceability

## 핵심 정의

요구사항 추적성은 요구사항과 설계, 개발, 테스트 산출물 간의 연관관계를 식별하고 추적하여 누락, 변경, 영향도, 검증 여부를 관리하는 활동이다.

```text
요구사항 -> 설계 -> 개발 -> 테스트
```

## 답안 키워드

- 연결/추적
- 누락 관리
- 변경 관리
- 영향도 분석
- 구현 여부 확인
- 검증 여부 확인
- RTM

## RTM

RTM은 Requirements Traceability Matrix의 약자로 요구사항 추적표를 의미한다.

## 시험용 목차

1. 개념
2. 필요성
3. 관리방안 또는 기대효과

## 현재 학습 상태

- 변경/누락 관리와 RTM은 비교적 안정적으로 회상한다.
- 영향도 분석은 2026-08-25에 무힌트 회상 성공했다.
- 영향도 분석은 2026-08-26에도 회상했다.
- 정의의 핵심인 요구사항-설계-개발-테스트 연결/추적은 2026-08-26에도 누락되어 반복 약점이다.
