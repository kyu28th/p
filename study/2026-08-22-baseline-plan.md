# 2026-08-22 Baseline Plan

## Purpose

2026-08-22 is the first baseline checkpoint. It is not a pass/fail prediction. The goal is to measure current answer-writing ability under conditions close to the real written exam.

## Unseen Set Rule

- Round 140 is reserved as the unseen mock-exam set until 2026-08-22.
- Do not expose round 140 questions during normal study, topic recommendation, example selection, or prediction work.
- Normal study and answer practice should use rounds 139 and earlier.
- If repository maintenance requires handling round 140 files, do not summarize or reveal the question contents to the user before the mock exam.

## Mock Exam Format

```text
100 minutes x 4 periods = 400 minutes
```

The mock exam uses round 140 information-management questions for the first time on 2026-08-22.

## Goals Before 2026-08-22

1. Identify high-frequency topics.
2. Restore basic knowledge for repeated topics.
3. Recognize areas changed in the last 6 years.
4. Learn answer structures for frequent topics.
5. Measure outline-writing ability.
6. Practice table/diagram use.
7. Experience timed answer writing.
8. Produce baseline data for the next study phase.

## Schedule

| Date | Focus |
|---|---|
| 2026-08-12 | Past-exam, topic, and coverage analysis; priority selection |
| 2026-08-13 ~ 2026-08-15 | High-frequency topic concentration, basic theory recovery, outline practice |
| 2026-08-16 ~ 2026-08-18 | Continue frequent topics, update recent changed topics, study old-source/current-exam gaps |
| 2026-08-19 ~ 2026-08-20 | Past-exam answer writing, repeated weakness analysis, weak-topic compression |
| 2026-08-21 | Minimum review of recent topics, definitions, answer keywords, comparison tables, diagrams, outlines |
| 2026-08-22 | Round 140 unseen mock exam under 400-minute conditions |

## Daily Study Loop

```text
select topic
-> check existing knowledge
-> understand concept
-> check related past exams
-> make 30-second to 3-minute outline
-> check answer keywords
-> make one table or diagram if useful
-> write an answer when needed
-> review
-> record weak point
-> reflect in review schedule
```

Reading source material alone does not count as completion. Whenever possible, the loop should reach at least recall, outline, or answer output.

## Visual Practice Rule

Use simple exam-writable visuals:

- Architecture diagram
- Process flow
- Concept map
- Comparison matrix
- Layer diagram
- Lifecycle
- Sequence
- Classification diagram
- Relationship diagram

The standard is whether the user can reproduce it by hand in 30 seconds to 1 minute.

## 2026-08-22 Evaluation Categories

For each question, classify the result:

- 충분히 알고 있음
- 알고 있으나 답안 구성 부족
- 개념만 알고 있음
- 들어봤으나 답안 불가
- 전혀 모름
- 시간 부족
- 문제 해석 실패

For each answer, check:

- definition
- structure
- answer keywords
- technical accuracy
- depth
- table
- diagram
- example
- differentiated insight
- conclusion
- time management

The result becomes the baseline for the next phase and the 141st-exam preparation plan.
