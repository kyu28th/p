## Software Configuration Management New Learning

사전지식:

| Question | User Answer | Result |
|---|---|---|
| 소프트웨어 형상관리가 뭐라고 생각해? | 버전관리 | PARTIAL INITIAL KNOWLEDGE |

학습 포인트:

- 형상관리는 버전관리보다 넓은 개념이다.
- 주요 활동은 `식별 -> 통제 -> 상태기록 -> 감사`이다.
- CI는 Configuration Item, 즉 형상항목이다.

주요 활동:

| 활동 | 공식 용어 | 의미 |
|---|---|---|
| 식별 | Configuration Identification | 무엇을 형상관리 대상으로 관리할지 결정하고 CI를 선정 |
| 통제 | Configuration Control | 변경 요청을 검토하고 승인/기각하며 변경을 통제 |
| 상태기록 | Configuration Status Accounting | 현재 버전, 변경 진행상태, 반영된 변경사항을 기록/보고 |
| 감사 | Configuration Audit | 승인된 변경사항이 실제 형상항목과 문서에 정확히 반영됐는지 검증 |
