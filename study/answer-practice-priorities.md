## Daily Writing Loop

```text
pick one past-exam question
-> 12 to 18 minute draft for 10-point, 35 to 45 minute draft for 25-point
-> self-review using templates/answer-review.md
-> update weak point
-> revise into answer skeleton
```

## Practice Rule

Do not wait for a perfect topic card. For `OK` topics, write now. For `NEW_GAP` and `UPDATE_NEEDED` topics, collect a one-page current note first, then write.
