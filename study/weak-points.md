# Weak Points

Weak points can come from answer reviews, recall tests, outline tests, or timed writing.

## Weak-Point Tags

| Tag | Meaning |
|---|---|
| weak-definition | Definition is vague or inaccurate |
| weak-structure | Answer lacks a clear frame |
| missing-keyword | Required scoring keywords are missing |
| weak-comparison | Comparison table or contrast is weak |
| weak-diagram | Diagram/table idea is missing or ineffective |
| weak-case | Application case is weak |
| weak-conclusion | Conclusion or implication is weak |
| time-over | Answer exceeded the time limit |
