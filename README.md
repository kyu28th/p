# ITPE Study

정보관리기술사 필기시험 합격을 목표로 운영하는 개인 학습 저장소입니다.

이 저장소는 Codex 세션의 기억에 의존하지 않고, 학습 자료와 결정사항을 GitHub에 지속적으로 남기기 위한 기준 저장소입니다.

## 운영 원칙

- GitHub repository를 프로젝트의 Single Source of Truth로 사용한다.
- PC 1, PC 2, Codex Cloud는 모두 같은 repository를 기준으로 작업한다.
- 원본 PDF/PPT는 기본적으로 로컬에 보관하고, GitHub에는 Markdown 중심의 학습 산출물을 저장한다.
- 중요한 전략, 진도, 취약점, 결정사항은 `PROJECT_CONTEXT.md`와 `study/` 아래에 기록한다.
- 출처가 있는 자료와 AI가 보충한 내용은 가능하면 구분한다.

## 주요 구조

```text
sources/      PDF/PPT 등 원천 자료에서 추출한 Markdown
knowledge/    시험 대비 토픽 단위 지식베이스
study/        학습 전략, 진도, 취약점, 세션 기록
answers/      내가 작성한 답안, 첨삭 답안, 모범답안
past-exams/   기출문제 및 분석
predictions/  예상문제와 예상 출제주제
trends/       신규 IT 기술 트렌드
```

## 현재 반영 자료

9주차 신규 PDF 묶음을 `sources/` 아래에 1차 Markdown 추출본으로 반영한다.

원본 파일은 GitHub에 저장하지 않고, 로컬 원본 보관소에 둔 뒤 Markdown 변환본과 토픽 지식베이스만 repository에 반영한다.

주의: 현재 반영된 PDF 묶음은 2016~2017 버전명이 포함되어 있고 파일 수정일은 2019년입니다. 최신 기술, 법/제도, 표준, 제품 동향은 반드시 별도 검증 후 `knowledge/`에 반영한다.
