# ITPE Study

Information Management Professional Engineer written-exam study repository.

## Purpose

This repository organizes study notes, topic cards, exam standards, past-exam indexes, and progress records in Markdown.

## Structure

```text
sources/      Source-derived Markdown notes
knowledge/    Topic-based study cards
study/        Progress, dashboard, weak points, and session logs
answers/      Draft answers and answer templates
past-exams/   Past-exam Markdown database and indexes
predictions/  Expected topics and trend tracking
trends/       Current IT trend notes
exam/         Exam standards and official reference notes
scripts/      Local conversion and maintenance scripts
```

## Notes

- Original PDF/PPT/HWP files are not stored in this repository.
- Markdown files may preserve source flow, page markers, and extraction notes for study use.
- Older source material should be checked against current standards, laws, products, and official exam criteria before being turned into final topic cards.
